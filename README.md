# VSM Industrial

Sitio corporativo estático construido con Astro, TypeScript y Tailwind CSS v4.

## Desarrollo

```bash
pnpm install
pnpm dev
```

## Cloudflare Pages

- Build command: `pnpm build`
- Output directory: `dist`

El proyecto usa `output: 'static'` y no requiere servidor, API o variables de entorno.
